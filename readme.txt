game engine features:

gameplay rooms, text dialog scenes
player character, without offscreen handling
tile objects
room transitions
sprite actor system (fae), with offscreen handling
projectiles, without offscreen handling
hud
color cycling
hdma
title screen, game over screen
saves room on death and can resume there


be sure to check out the visual effects test areas in ice cave 2



debug controls:


dpad: move

A: spawn a test object in the speech text system
B: stop moving
X: shoot
Y: slow movement

L: clear all shots
R: invert sprite palette 7

start: start the hud glowing for some reason
select: stops the above
